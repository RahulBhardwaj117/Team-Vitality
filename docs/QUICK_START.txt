└──────────────────────────────────────────────────────────────────────────────┘

Chatbot not appearing?
  → Check if you added the 2 lines to index.html
  → Verify you're logged in to the dashboard
  → Check browser console (F12) for errors

Messages not sending?
  → Ensure backend server is running (it is! ✅)
  → Check if .env file exists with API key
  → Verify MongoDB is running

AI not responding?
  → Check .env file has correct OPENAI_API_KEY
  → Chatbot will use fallback responses if AI fails
  → Check backend console for errors
