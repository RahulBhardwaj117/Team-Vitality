# 🚀 Quick Start Guide

## How to Use the Application

### ⚡ Quick 2-Step Process:

#### Step 1: Start the Backend Server
**Double-click** `START_BACKEND.bat`

- A **green window** will open
- Wait until you see: `✅ Alert Scheduler Engine Started`
- **DO NOT CLOSE THIS WINDOW!** (minimize it if you want)

#### Step 2: Open the Dashboard  
**Double-click** `index.html`

- Dashboard will open in your browser
- Everything works! 🎉

---

## ⚠️ IMPORTANT

### Keep Backend Window Open!
The green window with the backend server **MUST stay open** while you use the app.

### If You See "Backend Server Not Running" Error:
1. Check if the green backend window is still open
2. If closed, double-click `START_BACKEND.bat` again
3. Then refresh the dashboard (F5)

### To Stop Everything:
- Close the backend window (green terminal)
- Close the browser

---

## 📝 Pro Tips

- **Minimize** the backend window instead of closing it
- The backend shows useful logs - check it if something seems wrong
- If backend won't start, check the error messages in the window

---

## 🆘 Still Having Issues?

1. Make sure Python is installed: `python --version`
2. Check if port 8000 is already in use
3. Look for error messages in the backend window
